# Царская казна

Средневековое приложение для двоих: учёт денег, игровые задания с боссами и сокровищами, домашняя кладовая и список покупок по магазинам. Работает целиком на устройстве, без серверов, регистрации и платных сервисов. Все данные хранятся в IndexedDB браузера.

Версия 1.0.0 · сборка 2026-11-25

---

## 1. Как загрузить на GitHub Pages

Все файлы лежат прямо в корне архива, без папок. Так их и нужно положить в репозиторий.

1. Зайдите на github.com → «New repository». Имя, например, `tsarskaya-kazna`.
   На бесплатном тарифе GitHub Pages работает только для публичного репозитория (*Public*).
2. В пустом репозитории нажмите **Add file → Upload files**.
3. Распакуйте архив, выделите **все файлы** (не папку целиком) и перетащите их в окно загрузки. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите:
   *Source*: **Deploy from a branch**, *Branch*: **main**, папка **/(root)** → **Save**.
5. Через 1–2 минуты приложение будет доступно по адресу
   `https://ВАШ-ЛОГИН.github.io/tsarskaya-kazna/`

Пути в приложении относительные, поэтому оно работает и в подпапке репозитория, и на собственном домене.

> **Не загружайте в репозиторий** выгрузки из прежнего приложения (CSV) и резервные копии (JSON). Публичный репозиторий видят все, а в этих файлах ваши личные траты. Импорт делается прямо в приложении с устройства.

## 2. Как добавить на экран «Домой»

### iPad и iPhone
1. Откройте адрес приложения в **Safari**.
2. Нажмите **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **«Добавить»**.
3. Дальше запускайте «Казну» **только с иконки**.

Важно для iPad: данные приложения, открытого с иконки, и данные той же страницы во вкладке Safari хранятся **раздельно**. Если вести записи то там, то там, получатся две разные казны. Выберите иконку и пользуйтесь только ей.

### Android
Chrome → меню **⋮** → **«Установить приложение»** (или «Добавить на главный экран»).

### Первый запуск
Откройте приложение один раз при подключённом интернете. После этого оно работает и без сети: все файлы сохраняются на устройстве.

## 3. Перенос истории из «Тропы фонарей»

**Настройки и данные → Перенос из прежнего приложения → Выбрать CSV-файл.**

Приложение сначала показывает, что будет импортировано, и только потом записывает. Для вашей выгрузки `tropa-fonarey-operacii-2026-11-25.csv` проверка показала:

| Что | Количество | Сумма |
|---|---|---|
| Строк в файле | 82 | — |
| Расходы | 77 | 126 798 ₽ |
| Доходы | 4 | 126 919 ₽ |
| Переводы «Кошелёк → Наличка» | 1 | 5 000 ₽ |
| Нераспознанные строки | 0 | — |

- Все 11 статей из файла совпали со стандартными статьями «Казны», новые создавать не пришлось.
- Столбец «Кто» перенесён: в поле «Кто» появятся **Егор** и **Катя**.
- Даты сохраняются как в файле.
- Перевод между своими кошельками сохраняется в истории, но не меняет общую казну и не попадает в аналитику: деньги не покидали семью.
- Повторный импорт того же файла ничего не задвоит: каждая строка получает свой отпечаток.

**Про остаток.** В выгрузке нет начального остатка, только операции за 1–23 ноября. Если просто импортировать, «Золото в казне» покажет разницу доходов и расходов: **+121 ₽**. Чтобы казна совпала с реальностью, впишите в окне импорта поле «Сколько денег у вас сейчас на самом деле». Приложение само подберёт начальный остаток. Его можно поменять и позже: **Настройки → Казна и семья → Начальный остаток**.

Подходит и CSV из других приложений: обязательны столбцы «Дата» и «Сумма», необязательны «Тип», «Категория», «Название», «Заметка», «Кто», «Откуда», «Куда». Если файл не подходит, приложение назовёт причину, покажет нужный формат и ничего не запишет.

## 4. Резервные копии — обязательно прочитайте

Данные живут **только на этом устройстве**. Их уничтожат:
- очистка истории и данных сайтов в Safari или Chrome;
- удаление иконки приложения с экрана «Домой» на iPad;
- сброс браузера или устройства, переход на новый планшет.

Обновление приложения, перезагрузка планшета, закрытие вкладки и работа без интернета данные **не** удаляют.

### Как сделать копию
**Настройки и данные → Резервные копии → Создать резервную копию.**
На iPad откроется меню «Поделиться» → выберите **«Сохранить в Файлы»** (лучше в iCloud Drive) или отправьте файл себе в мессенджер. Файл называется `tsarskaya-kazna-ГГГГ-ММ-ДД.json`, в нём всё: казна, игра, кладовая и настройки.

Делайте копию раз в неделю. Если копии давно не было, приложение напомнит об этом после 14 дней.

### Как восстановить
**Настройки и данные → Восстановить из файла** → выберите JSON. Приложение проверит подпись и версию файла, покажет, что в нём, и предупредит, что текущие данные будут заменены. Копию от более новой версии приложения оно откажется загружать и попросит сначала обновиться.

### Снимки на устройстве
Кроме файлов, приложение само хранит до 8 снимков внутри устройства: ежедневный, а также перед импортом, восстановлением и полным сбросом. Вернуть снимок: **Настройки → Снимки на устройстве → Вернуть**. Снимки не заменяют файловую копию: при очистке данных браузера они исчезнут вместе со всем остальным.

### Защита от автоочистки
В разделе «Сохранность» есть кнопка **«Включить» защиту**. Браузер охотнее разрешает её приложениям, установленным на экран «Домой».

## 5. Как обновить приложение

1. Загрузите новые файлы в репозиторий поверх старых (Add file → Upload files → Commit).
2. Откройте приложение. Внизу появится **«Доступна новая версия… Обновить»**. Нажмите — данные останутся на месте.

Структура базы версионируется, и обновления только добавляют новое. Старые записи не удаляются.

## 6. Что внутри

### Царская казна
- **Главная.** Сокровищница с сундуком, который наполняется золотом вместе с казной, пустеет и зарастает паутиной при минусе. При доходе монеты летят в сундук, при расходе разлетаются, а слуга-ключник Прошка радуется, грустит, удивляется, считает монеты, вздыхает, разводит руками и потирает ладони. Его фразы случайны и не повторяются подряд; свои фразы можно добавить в настройках.
- **Путь к сокровищам.** Карта на 40 уровней через восемь земель: Торговые ряды, Подписные горы, Застава у моста, Весёлая ярмарка, Болото отсрочек, Чёрный замок, Дремучий лес, Окиян-море. Царь и царица действительно идут по дороге, флажки поднимаются, пройденная дорога прорисовывается.
- **Восемь боссов** (уровни 5–40): Купец Обдирала, Змей Подписочный, Мытарь Пошлинник, Кот Транжира, Улита Проволочка, Кощей Скупой, Баба Яга Процентная, Чудо-Юдо Инфляция. У каждого свой облик, логово, характер, анимация и реакция на поражение. Состояния: не открыт → ожидает → противостояние → побеждён → сокровище открыто.
- **Сокровища.** Желанные покупки: название, стоимость, описание, значок или фото, босс-хранитель. Чем дороже мечта, тем богаче ларец: от медного ларчика до царской сокровищницы. После победы открывается сундук с наградой. Стоимость из казны **не** списывается.
- **Казначей.** При входе он вздыхает, макает перо и разворачивает свиток. Доходы и расходы с суммой, статьёй, описанием, датой, «Кто», местом покупки и комментарием. Есть поиск, фильтры, сортировка, правка, удаление с подтверждением и отменой. Статьи создаются с названием, значком, цветом и порядком; при удалении статьи история не теряется.
- **Регулярные платежи**: ежедневно, еженедельно, ежемесячно (с числом месяца; 31-е в коротком месяце становится последним днём), ежегодно или свой интервал, с датами начала и окончания. Пропущенные за время закрытия даты записываются при следующем открытии ровно один раз.
- **Аналитика.** Расходы и доходы по статьям, динамика, накопительный чистый поток, сравнение с прошлым периодом, крупнейшие траты, средние траты по дням недели и средний чек. Периоды: сегодня, вчера, текущая и прошлая неделя, текущий и прошлый месяц, 7/30/90 дней, свой диапазон. Можно смотреть всю семью или одного человека.
- **Колесо заданий.** Шут Гороховый охает, крутит колесо, смеётся и бросает кинжал. Задание выбирается честным генератором случайных чисел, колесо останавливается ровно на выбранном секторе. У шута 35 реплик.
- **Задания и цели**: регулярные (каждые N дней), еженедельные, ежемесячные, разовые и для колеса. У каждой задаются опыт, число шагов, срок и повтор. Повторяющиеся сами появляются в новом периоде, опыт за одно задание дважды не начисляется, просроченные уходят в летопись без опыта. Серии отмечаются, есть архив и «Летопись подвигов».
- **Бояре.** Восемь бояр в думе синхронно кланяются, один выходит вперёд с советом. Советы считаются только по вашим записям: сравнение периодов, крупнейшая доля, рост и снижение по статьям, подписки, повторяющиеся платежи, необычные траты, средний чек и частота, структура расходов, итог месяца, максимум за три месяца, дни недели, дни без трат. Кнопка «На чём основано» показывает цифры и записи, из которых совет выведен. Если данных мало, боярин честно скажет, что сведений пока маловато.

### Кладовая царской семьи
- **Запасы.** Повар режет овощи, замечает вас, удивляется и указывает на список. Товары с количеством, единицей, желаемым запасом, необязательным порогом и магазинами (можно несколько). Статусы: достаточно, заканчивается, закончилось. Заканчивающиеся поднимаются наверх. Непостоянные товары учитываются, но в корзину сами не попадают.
- **Каталог на 725 позиций** с синонимами. Поиск понимает часть слова, синонимы («картоха» → картофель) и небольшие опечатки («малоко» → молоко). Дубли не создаются: найденный товар помечается «уже в кладовой».
- **Корзина.** Сама собирается из заканчивающихся товаров и считает, сколько купить до желаемого запаса. Разбита по магазинам. Позицию можно отметить купленной (с предложением обновить запас), изменить количество, перенести в другой магазин, убрать, добавить вручную, скопировать список или распечатать, очистить с подтверждением. Купленное сегодня видно отдельно и возвращается одним нажатием.
- **Управление.** Категории, магазины, каталог, единицы измерения (и свои), настройки, импорт и экспорт, история запасов и покупок.

### Общее
- Настройки и данные: сохранность, копии, снимки, импорт, начальный остаток, участники, фразы слуги, анимация (полная, умеренная, без анимации), звук и громкость, компактные списки и сцены, журнал событий.
- Звуки синтезируются в браузере, отдельных аудиофайлов нет.
- Отмена последних действий, подтверждение важных операций, проверка целостности базы при запуске.

### Правила игры
**1 опыт = 1 шаг героев по дороге. 100 шагов = 1 уровень.** Всего 40 уровней, босс стоит в конце каждого пятого. Опыт даётся за выполненные задания, его количество вы назначаете сами.

«Шагов в задании» — сколько отметок нужно сделать, чтобы его выполнить. Например, «Неделя без доставки» — это 7 шагов, по одному в день.

## 7. Каталог товаров

Встроенный каталог (`products.json`) составлен для этого приложения. Это распространённые названия продуктов и бытовых товаров с единицами и синонимами, **без артикулов, цен и сведений об ассортименте сетей**. Список магазинов — ваш личный справочник.

Файл `kladovaya_product_catalog.json`, о котором говорилось в задании, к сообщению не прикрепился. Подключить его можно двумя способами:
- **Управление → Импорт и экспорт → Импорт каталога** (понимает массив товаров или объект с полем `items`/`products`, поля `name`/`название`, `category`, `unit`, `synonyms`, `stores`);
- или просто положить файл с этим именем в корень репозитория: приложение подхватит его при запуске.

Ваши правки и добавления хранятся отдельно от исходного каталога и попадают в резервную копию.

## 8. Файлы

|---|---|
| `index.html` | оболочка приложения |

| `app.js` | запуск, навигация, начальные данные, проверка целостности |
| `database.js` | хранилище IndexedDB: транзакции, журнал восстановления, миграции, копии, снимки |
| `ui.js`, `icons.js`, `animations.js` | окна, формы, даты, звук; иконки; эффекты |
| `art.js`, `bosses.js`, `scenes.js` | персонажи, боссы, сундуки, сцены и карта (векторная графика) |
| `home.js`, `finance.js`, `analytics.js`, `boyars.js`, `game.js` | экраны казны |
| `pantry.js` | кладовая, корзина, управление |
| `importer.js`, `settings.js` | импорт CSV; настройки и данные |
| `products.json` | каталог товаров |
| `manifest.json`, `service-worker.js` | установка на экран «Домой» и работа без интернета |
| `icon-*.png`, `apple-touch-icon.png`, `favicon-32.png` | иконки |
| `texture-*.jpg` | текстуры пергамента и дерева |
| `lora.woff`, `lora-italic.woff`, `OFL-Lora.txt` | шрифт Lora (SIL Open Font License 1.1) |

Все иллюстрации — оригинальная векторная графика, нарисованная для этого приложения. Персонажи анимируются по частям (голова, руки, мимика), поэтому файлов-картинок персонажей нет.
